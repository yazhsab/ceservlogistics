# CServe mobile core

Private shared Flutter package for the CServe Driver and CServe Scanner apps.
It provides:

- authenticated OpenAPI client methods and refresh-token rotation;
- secure session and device identity storage;
- delivery, shipment and scanning DTOs;
- an offline scan queue with stable device event IDs;
- shared visual tokens and mobile theme.

This package is repository-internal and is not published to pub.dev.
